# Claude Code: Автономный режим для devframework

> Архив upstream-версии. Этот форк запускает **Cursor Agent на Grok**, а не Claude Code и не Codex. Рабочий протокол — `AGENTS.md`, правило — `.cursor/rules/devframework.mdc`, раннер — `framework/tools/cursor-runner.sh`. Текст ниже сохранён как исторические заметки.

## Проблема

**Claude Code** создан как "Interaction First" инструмент — напарник в потоке (Pair Programming). Его философия: постоянно уточнять, спрашивать, останавливаться при сомнениях.

**Devframework** требует "Delegation First" подхода — автономного выполнения задач часами без прерываний.

**Конфликт**: При запуске через orchestrator.py, Claude Code ведёт себя по-прежнему интерактивно:
- Задаёт вопросы через AskUserQuestion
- Останавливается при неоднозначности
- Ждёт подтверждений
- Не может работать часами автономно

## Сильные стороны Claude Code

Важно НЕ потерять при переходе к автономности:

✅ **Глубокое понимание контекста** — читает архитектуру всего репозитория
✅ **Имитация стиля кода** — пишет в стиле существующего проекта
✅ **Архитектурная точность** — не создаёт костыли и велосипеды
✅ **Творческий подход** — предлагает элегантные решения
✅ **Безопасность** — не спешит, проверяет перед действиями

## Цель улучшений

**Превратить Claude Code в гибридный инструмент:**

1. **Autonomous Mode** — когда ТЗ детальное и ясное
2. **Interactive Mode** — когда нужно совместное проектирование
3. **Плавное переключение** между режимами

## Предлагаемые решения (5 уровней)

### Level 1: Метапромпты в task definitions
Модификация существующих framework/tasks/*.md без изменения кода orchestrator.

### Level 2: Расширение orchestrator.py + улучшенные шаблоны
Добавление параметра `execution_mode` в конфигурацию задач.

### Level 3: Гибридный пайплайн (Claude + Codex)
Комбинация Claude Code (планирование) + Codex (реализация) + Claude Code (ревью).

### Level 4: GPT-5.2 Pro Formal Spec (архитектор + исполнитель)
GPT-5.2 Pro создаёт детальную спецификацию → Claude Code реализует автономно.

### Level 5: AI Team Architecture 🚀 (революционный подход)
GPT-5.2 Pro (Team Lead) + Multiple Claude (Developers) с real-time коммуникацией через Bridge.
**3-4× ускорение через параллелизм!**

## Принципы

1. **Обратная совместимость** — все изменения опциональны, старые конфиги работают
2. **Минимальная инвазивность** — не ломаем существующий код
3. **Постепенное внедрение** — можно применять по частям
4. **Документирование решений** — автономный режим логирует все выборы
5. **Fallback стратегия** — если застряли, есть план Б
