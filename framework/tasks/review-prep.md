# Task: Review Handoff Prep

## Goal
Prepare the package for an independent review after development is done.

## Inputs
- Current commit/branch
- `framework/docs/definition-of-done.md`
- `framework/review/review-brief.md`

## Outputs
- `framework/review/handoff.md`
- `framework/review/bundle.md`
- `framework/review/test-results.md` (if tests were run)

## Rules
- Do not change code.
- Record the commands and the run results.
- Call out the higher-risk areas.

## Done When
- The handoff is filled in, and test results are attached or it is explicitly noted that tests were not run.
