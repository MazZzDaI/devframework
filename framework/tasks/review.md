# Task: Independent Review

## Goal
Run an independent code review and QA of the finished implementation.

## Inputs
- `framework/review/test-plan.md`
- `framework/review/review-brief.md`
- `framework/review/handoff.md`
- `framework/docs/definition-of-done.md`
- `framework/docs/orchestrator-run-summary.md` (if present)

## Outputs
- `framework/review/code-review-report.md`
- `framework/review/bug-report.md`
- `framework/review/qa-coverage.md`
- `framework/review/test-results.md` (if tests were run)

## Rules
- Do not change code, only reports.
- Refer to specific files and sections.
- State severity and how to reproduce each issue.

## Done When
- The reports are filled in and reproducible.
- Gaps and risks are called out explicitly.
